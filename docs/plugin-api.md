# Проект API плагинов v1

Статус — проект интерфейса. В AirDesk 0.7.0 исполнение плагинов не включено. Приложение не сканирует каталоги расширений и не загружает сторонние сборки.

Манифест плагина задаёт `id` в формате reverse DNS, `version`, поддерживаемую основную версию `apiVersion: 1`, список запрашиваемых `permissions`, хеши файлов и данные издателя. Начальный набор разрешений включает `read.telemetry` для выбранных метрик и `read.frames` для показателей кадров по отдельному согласию. Пустой набор запрещает чтение. Доступ к драйверу, PWM, профилям управления и процессам игр в v1 не предусмотрен.

Предлагаемый транспорт — сообщения JSON через именованный канал с явным ACL и идентификатором создаваемого процесса. Каждое сообщение содержит `apiVersion`, `type` и `payload`. Предлагаемый предел сообщения — 64 КиБ, а частота потоковых данных — один снимок в секунду. Оболочка сообщает `hello` с предоставленными разрешениями, передаёт выбранные обезличенные снимки через `telemetry` или `frames`, закрывает сеанс сообщением `shutdown`. Процесс отвечает `ready` и может посылать `status`. Несовместимую версию или неожиданный тип сообщения хост отклоняет. Данные не содержат серийных номеров, путей, полных имён процессов и произвольных системных отчётов.

До реализации хоста нужны отдельный процесс с ограниченным токеном Windows и явным запретом доступа к драйверу, проверка цепочки издателя и хеша полезной нагрузки, подтверждение каждого набора прав и отзыв разрешений. Предусмотрены тайм-ауты запуска и остановки, ограничение памяти и CPU, завершение только процесса расширения и сброс очереди при ошибке. Хост плагинов не запускается из повышенного AirDesk, не является частью аппаратного исполнителя и полностью отключается одним переключателем.
