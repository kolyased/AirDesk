# Установка, обновление и откат AirDesk

## Первый запуск

1. Для переносимой сборки проверьте SHA-256, распакуйте ZIP целиком и запустите `AirDesk.exe` из папки `AirDesk-<версия>`. Для установки используйте Setup для Windows x64. Он создаёт ярлык в меню «Пуск» и предлагает необязательный запуск при входе в Windows.
2. В «Настройки → Версия и обновления» сверяйте версию и Git SHA со сведениями в файле `BUILD.txt`. Установка AirDesk и обычный мониторинг работают от имени текущего пользователя.
3. На вкладке «Диагностика» проверьте регистрацию PawnIO, доступность файла драйвера, права сеанса и наличие показаний Super I/O. Температуры и загрузка, которые Windows и библиотека могут прочитать без драйвера, остаются в интерфейсе.
4. Если нужны дополнительные датчики, откройте официальную страницу PawnIO через диагностику. Это отдельный драйвер ядра Windows, его установка требует прав администратора. Сверьте подпись установщика и отмените установку, если не согласны с условиями. Перезапустите AirDesk после установки драйвера. [Официальный сайт PawnIO](https://pawnio.eu/)
5. Для управления на проверенной плате завершите AirDesk через пункт «Выход» в трее и отдельно запустите `AirDesk.exe` от имени администратора. После отмены UAC доступен обычный запуск. Режим `--monitor-only` и запуск при входе в Windows блокируют команды управления на весь сеанс. Дальше следуйте [инструкции по калибровке](../README.md#управление-охлаждением).

Пользовательские настройки, история и привязка находятся в `%LOCALAPPDATA%\AirDesk` у обеих сборок. Удаление установщика убирает файлы приложения и ярлык. Запись автозапуска удаляется только если указывает на этот установленный экземпляр. Пользовательский каталог и PawnIO сохраняются.

## Обновление

В «Настройки → Версия и обновления» нажмите «Проверить обновления». AirDesk обращается к API GitHub только после нажатия и ищет стабильный релиз `vX.Y.Z` проекта. После согласия на загрузку приложение сверяет размер и SHA-256 с данными GitHub, проверяет Authenticode установщика, совпадение сертификата с текущим подписанным AirDesk и номер версии файла. Неподписанная сборка может проверять наличие релизов, но не может подтвердить издателя для скачивания.

1. Сохраните предыдущую сборку и закройте AirDesk через трей. Если показано предупреждение о возврате охлаждения, проверьте BIOS/EC и завершите восстановление в AirDesk.
2. С закрытым приложением скопируйте `%LOCALAPPDATA%\AirDesk` в отдельное место. Копия включает настройки, журнал, привязку и историю. Для переносимой версии удобно распаковать новую сборку рядом с прежней.
3. Запустите проверенный установщик вручную. Установщик блокирует замену файлов при запущенном AirDesk и при незавершённом аппаратном захвате. При необходимости повторите запуск после штатного выхода.

## Возврат к прежней версии

Выйдите через трей и проверьте возврат управления BIOS/EC. Скопируйте текущие данные отдельно. Для установленной версии удалите новую сборку через «Приложения» Windows и установите прежний подписанный пакет. Для переносимой версии запустите сохранённую копию из старой папки. При необходимости восстановите сохранённые перед обновлением файлы настроек, истории и привязки после выхода из AirDesk. Настройки неизвестной будущей схемы сохраняются при чтении, но редактирование такой схемы в старой версии не поддерживается. Машинную отметку захвата проверяйте через AirDesk после восстановления BIOS/EC.
