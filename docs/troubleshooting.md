# Типовые проблемы AirDesk

| Что видно | Что проверить |
|---|---|
| В диагностике обнаружен FanControl или другой контроллер | Аппаратная запись блокируется при обнаружении конфликта. Для наблюдения ничего закрывать не требуется. При намерении передать управление AirDesk завершите другой контроллер через его интерфейс и проверьте список в диагностике |
| PawnIO не найден | Обычный мониторинг продолжает работать. Для дополнительных датчиков откройте ссылку в диагностике и следуйте [инструкции](installation.md) |
| Windows показывает UAC | Это требуется для установки PawnIO или отдельного запуска AirDesk с правами для записи. Для мониторинга запустите AirDesk обычным способом. При отказе UAC снова откройте обычный экземпляр |
| Канал управления не найден | Сверьте плату, BIOS, PawnIO, версию библиотеки и доступ к Super I/O. Неподдерживаемая конфигурация остаётся в мониторинге. Номер канала не доказывает назначение разъёма |
| Значение отсутствует, устарело или не определено | Посмотрите время и качество в «Устройствах» или «Диагностике». Проверьте, выдаёт ли датчик данные в BIOS или программе производителя. Неопознанные входы скрыты из сводки |
| Поменялся процент команды, а RPM не вырос | Проверьте режим PWM/DC, схему хаба и его единственный тахометр. Убедитесь, какой вентилятор физически подключён к входу RPM. При неподтверждённом отклике AirDesk возвращает управление BIOS/EC и не сохраняет привязку |
| Возврат BIOS/EC не подтверждён | Проверьте охлаждение с экрана BIOS/EC после перезапуска. Заново оцените температуры и обороты, затем подтвердите восстановление на вкладке «Охлаждение». В интерфейсе «Выход» ожидает результат, а крестик лишь скрывает главное окно |
| CSV PresentMon отсутствует или не читается | Проверьте путь и разрешение на чтение файла. При блокировке CSV используйте запись через `--output_stdout` по [инструкции FPS](fps-osd.md) |
| Заголовок CSV PresentMon неполный или неподходящий | Дождитесь начала записи или проверьте консоль PresentMon. Используйте `--v1_metrics` и UTF-8 |
| FPS остаётся прочерком | Сверьте PID и появление новых строк в выбранном CSV. При остановке записи или ошибке доступа ETW проверьте консоль PresentMon. Обычные датчики продолжают работать |

Для обращения в GitHub используйте отредактированный предпросмотр из диагностики и [правила отправки отчёта](../CONTRIBUTING.md#как-передать-отчёт-датчиков).
