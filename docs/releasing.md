# Сборка и публикация AirDesk

Канонический исходный код находится в репозитории [kolyased/AirDesk](https://github.com/kolyased/AirDesk). Основная ветка — `main`. До слияния тестовые сборки доступны из рабочей ветки. Единственный номер версии задаётся в `Directory.Build.props`. Сборка записывает полный Git SHA в свойства `AirDesk.exe` и `BUILD.txt`. Старые локальные каталоги и архивы определяются по этим данным, а для сборок без SHA — по содержимому и контрольной сумме.

На Windows используйте .NET 10 SDK и PowerShell 7. Для установщика нужен проверенный Inno Setup. Версия 6.7.4 использовалась для проверки. Требования его лицензии к коммерческому использованию действуют отдельно. [Загрузка и проверка Inno Setup](https://jrsoftware.org/inno-setup/downloads)

```powershell
dotnet build AirDesk.slnx -c Release
dotnet test AirDesk.slnx -c Release --logger "trx;LogFileName=airdesk.trx"
pwsh -File scripts/Package.ps1 -Iscc 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
pwsh -File scripts/Test-Package.ps1
```

Без параметра `-Iscc` создаётся Portable ZIP. При сборке обоих пакетов установщик и ZIP используют одну папку публикации, включая локальный .NET, инструкции и лицензии. Скрипт сверяет опубликованные зависимости, версию, Git SHA и отсутствие отдельного драйвера PawnIO. Статус подписей и модификаций рабочей копии указан в `BUILD.txt`. SHA-256 обоих пакетов находится в `AirDesk-<версия>-SHA256.txt`.

GitHub Actions проверяет установку x64-пакета на Windows 11 ARM64 под эмуляцией x64. В артефакте `AirDesk-Windows-11-installer-evidence` сохраняются версия Windows, журналы установки и отчёты оконной проверки. Для ручного повтора в отдельной учётной записи используйте `scripts/Test-InstallerUpgrade.ps1` с параметрами `-PreviousSetup` и `-CurrentSetup`.

## Условия стабильной публикации

1. Из чистого checkout главной ветки соберите оба пакета командой с `-Release`, `-Iscc`, `-SignTool` и `-CertificateThumbprint`. Сертификат доверенного издателя должен быть доступен Windows SignTool в хранилище сертификатов пользователя. Скрипт подписывает AirDesk EXE и DLL, включает подписанный деинсталлятор в Inno Setup и подписывает Setup. Зависимости поставщиков сохраняют их оригинальный вид.
2. Сверьте SHA и версию пакетов с Git. Проверьте доверие Windows к подписи, наличие временной метки и того же сертификата у приложения и установщика. Подпись требуется для стабильной публикации, а SHA-256 подтверждает совпадение файла с опубликованным.
3. На чистых Windows 10 22H2 и Windows 11 выполните установку, запуск без PawnIO, автозапуск с наблюдением, удаление с сохранением пользовательского каталога, обновление и возврат к предыдущей версии. Проверьте блокировку установки в работающем AirDesk. Запись вентилятора проверяется отдельно по [плану аппаратных испытаний](validation.md).
4. В [GitHub Releases](https://github.com/kolyased/AirDesk/releases) опубликуйте тег `vX.Y.Z`, Portable ZIP, `AirDesk-X.Y.Z-Setup-win-x64.exe` и файл контрольных сумм. API GitHub должен вернуть `digest` для Setup. Опубликуйте записи CHANGELOG и проверенный Git SHA. Неподписанные материалы из рабочей ветки предназначены для тестирования; не публикуйте их как стабильный выпуск.

Храните ключ подписи у выпускающего владельца. При смене сертификата выполните один ручной переход на пакет, подпись и контрольную сумму которого пользователь проверил по официальному релизу. Последующие обновления снова сверяют сертификат установленного AirDesk.
