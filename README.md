# AirDesk

Простая утилита для Windows 10/11 x64: температуры, нагрузка и вентиляторы материнской платы. Версия 0.2 — ранняя локальная версия.

## Запуск

Откройте `AirDesk.exe` из папки приложения и подтвердите UAC. Для мониторинга платы и CPU нужен [PawnIO](https://pawnio.com/), на компьютере, где разрабатывался проект, он уже установлен. Драйвер автоматически не устанавливается. Готовая сборка включает .NET runtime.

- CPU, RAM, GPU, активность дисков и график CPU.
- Температуры CPU, SSD, GPU и доступных датчиков платы.
- Значок в трее: щелчок — компактная панель, двойной щелчок — окно, правая кнопка — меню и выход.
- Крестик скрывает окно. Программа продолжает работать, пока пользователь вошёл в Windows. Это не системная служба.
- `AirDesk.exe --tray` запускает без основного окна. Автозапуск не устанавливается.
- Для управления завершите FanControl и MSI Afterburner. Для этого ПК выбран подтверждённый канал Fan #2; выберите режим и нажмите «Применить». Программа не изменяет вентиляторы GPU.
- «Вернуть всё BIOS» снимает управление со всех захваченных каналов. При обычном выходе оно также возвращается BIOS.

## Регулировка

Автоматическая кривая фиксирована: 40°C → 40%, 60°C → 65%, 75°C → 90%, 85°C → 100%. Ручной диапазон 40–100%. Понижение плавное, рост немедленный. Потеря температуры CPU или CPU ≥85°C задаёт 100%, в том числе в ручном режиме. Режимы не восстанавливаются автоматически после перезапуска.

Минимум 40% не гарантирует вращение любого вентилятора: проверьте фактические обороты и подключение PWM/DC. Программа не определяет физическое назначение разъёмов. В основном окне показаны карточки CPU, GPU и накопителей; технические датчики доступны в JSON-отчёте. Не используйте неизвестные температуры как достоверную температуру VRM/чипсета. Показатели нагрузки могут отличаться от Диспетчера задач из-за источника и интервала измерений; списка процессов в этой версии нет.

Ограничения: программная защита работает только пока процесс и драйвер отвечают. Аварийное завершение, зависание или отключение питания не гарантируют возврат BIOS; сохраняйте аппаратные защиты BIOS. Детектор конфликтов охватывает FanControl/MSI Afterburner, но не все утилиты. Не запускайте другие регуляторы одновременно. В этой версии нет отдельного watchdog-сервиса. Неподдерживаемые показатели отображаются `—`.

## Сборка и тесты

Нужен .NET 10 SDK на Windows.

```powershell
dotnet build src/AirDesk -c Release
dotnet run --project tests -c Release
dotnet publish src/AirDesk -c Release -r win-x64 --self-contained true -o dist/AirDesk
```

Сборка не зависит от установленного FanControl. LibreHardwareMonitorLib 0.9.6 загружается из NuGet. Логи ошибок: `%LOCALAPPDATA%/AirDesk/errors.log`. Отчёт датчиков экспортируется вручную в JSON. Нет телеметрии, облака и отправки отчётов.

## Открытый код

Код AirDesk — MIT, библиотека LibreHardwareMonitor — MPL-2.0. См. `THIRD-PARTY-NOTICES.md`. Перед публичным релизом нужны проверка на другом оборудовании, испытания регулировки под нагрузкой, аудит восстановления после сбоев и подпись исполняемых файлов. Сборка и тесты запускаются автоматически через GitHub Actions.

Вклад: откройте issue с моделью платы, версией Windows и экспортом датчиков (проверьте содержимое перед публикацией). Для pull request выполните тесты; изменения управления требуют описания проверки на реальном оборудовании.

## Изменения 0.2

- Температура видеокарты отображается в трее и на основной карточке.
- Основные температуры вынесены в отдельные карточки, длинный список убран.
- Fan #2 — канал с подтверждённым откликом на этом ПК. Fan #1 показан только для наблюдения: он может относиться к помпе или радиатору. Каналы без оборотов скрыты.
- «Проверить отклик · 8 сек» временно задаёт 100%, сравнивает RPM и возвращает прежний режим (или BIOS). Увеличение более 10% отмечается как подтверждённый отклик. Отсутствие роста не доказывает неисправность: вентилятор уже может работать на максимуме.
- Результат реального теста: Fan #2 1458 → 1888 об/мин; после возврата BIOS — около 1472 об/мин. Физическое назначение группы ещё не установлено.
- Для ручного режима: выбрать «Вручную», выставить процент, нажать «Применить». Статус показывает записанную команду и обороты; их изменение занимает несколько секунд.
- Ползунок выключен в автоматическом режиме, поскольку там процент задаёт температурная кривая.
- Температура RAM показывается только при доступном датчике; отсутствие данных не означает отсутствия датчика физически.

В версии 0.2 упрощённое управление настроено на NCT6779D / Fan #2 этого ПК. На других платах не выбирается случайный канал: может работать только мониторинг. Это ограничение первой аппаратной конфигурации, а не универсальная схема подключения вентиляторов.
